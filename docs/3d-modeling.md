# 3D Modeling gallery (`/3d-modeling`)

- **Single source of truth:** `src/data/models3d.js` (models, categories, views, verified counts).
  It feeds `/3d-modeling` (`src/pages/Modeling3D.vue` + `src/components/modeling/ModelDialog.vue`),
  the home teaser (`src/components/ModelingTeaser.vue`) and the Roblox / Game Dev preview
  (`src/components/modeling/ModelingShowcase.vue`).
- **Counts** (triangles, parts, materials, bones) come from the Blender project's
  `export/export_manifest.json`, confirmed by the FBX reimport check (`verify_report.txt`, ALL_OK).
- **Images:** originals stay in the Blender project (`renders/`, 2048² PNG). The site only ships WebP
  copies generated by `scripts/build-3d-images.mjs` (needs ffmpeg with libwebp):

  ```sh
  RENDERS_DIR=~/Downloads/job/Roblox_Props_Portfolio/renders node scripts/build-3d-images.mjs
  ```

  Output: `public/images/3d/<slug>/<view>-<width>.webp` — 480/960/1600 px for square views,
  800/1280/2000 px for wide (3:2) views. Cards load the small size lazily; the dialog loads the
  middle size through `srcset`; "Enlarge" loads the largest.
- **Adding a model:** add an entry with its `views` (render filename in `src`), run the script, then
  `node --test tests/` (checks every image exists and that the copy avoids unverified claims).
- Deep links: `/3d-modeling?model=<slug>` opens a model directly.
